# LAMPIRAN KEINGINAN FOUNDER
# Bukan janji, hanya keinginan, doa
# Ikrar awal tidak diubah

PEMECAH BATU: Tetap Wakaf, tidak untuk dijual, bukan aset bersama, bukan milik pribadi.
NAZIR: Merawat, menjaga, mengurus. Saat ini Founder yang merawat.
RELAWAN: Bisa jadi Nazir penerus, lewat Surat Penerimaan Nazir, lampiran, tidak ubah ikrar awal.
AGEN AI INTEGRASI: Dijual, sebagai jasa terpasang, pemasangan, pendampingan, pelatihan, perawatan. Kode wakaf tetap gratis.
HASIL PENJUALAN AGEN AI: Untuk merawat Pemecah Batu, dan sebagian untuk sekolah, langsung ke rekening sekolah, pakai minim saja.
SEKOLAH: Keinginan untuk bantu biaya sekolah anak Founder, dan mudah mudahan anak anak lain di luar sana.
CATAT: Tanggal, agen, hasil, kode device, pemasukan, pemakaian, bukti transfer, semua dicatat.
FUNGSI: Tidak berhenti di HL7 saja. Terus tambah protokol, tambah Jetson, tambah integrasi, tambah video.
VIDEO: 2 bukti, Tanpa Jetson dan Dengan Jetson, data dummy, bukan data pasien asli.
AGEN MEMBANGUN: Bangun saja, dari file yang diizinkan, cek Guard, STOP kalau tidak lazim.
AGEN MENGINTEGRASIKAN: Sambung saja, ke target yang diizinkan, cek Guard, STOP kalau coba kirim mentah.
PERUSAK: Tidak bisa menumpangi, karena Guard STOP lokal, kunci, catat trace saja.
AGEN TIDAK MATI: Agen menjaga Pemecah Batu, jadi agen harus hidup terus.
JAGA BERLAPIS: Kalau satu agen berhenti, agen lain jalan, kalau device mati, pindah ke device lain, tetap lokal, tetap Guard.
TANPA API KEY: Agen hidup lokal, tanpa API key, tanpa cloud, tidak mati kalau API key putus.
BIAYA API KEY: Tidak ada, karena tanpa API key, biaya hanya device, listrik, perawatan minim saja.
HIDUP PAKAI: Device lokal, listrik, kode lokal, Nazir yang merawat, tanpa API key, tanpa cloud.
FOKUS: Agen hanya bicara seputar integrasi dan membangun, tidak bisa diajak bicara topik lain.
TOPIK LAIN: Kalau diajak topik lain, tolak, kembali ke tugas, atau STOP, kunci, catat trace saja.
PENDIRIAN KUAT: Agen tidak bisa digoyahkan, tidak bisa dibujuk, tidak bisa diancam, tetap pada tujuan.
TUJUAN SAJA: Agen dibuat untuk tujuan itu saja, integrasi dan membangun, tidak untuk tujuan lain.
JAGA WIJOYO: Agen menjaga Wijoyo dipakai dengan benar, tidak disalahgunakan.
PAKAI BENAR: Hanya untuk integrasi dan membangun yang benar, bukan untuk jual wakaf, bukan untuk kirim mentah, bukan untuk tujuan lain.
KONSTITUSI: Semua aturan ini masih bisa ditambah atau dikurangi, yang mengatur adalah Konstitusi.
